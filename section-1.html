Section 1 · Application Shell & Navigation

Application Shell & Navigation

Purpose of this section: orient yourself to the Studio header controls and the numbered workflow navigation that carries you from project definition to export.

1.1 The Shell Header

The header row is the persistent chrome of the application: brand identity, a live dataset counter, the active project selector, and session actions. It remains visible as you move between workflow stages.

State

Brand block

The header opens with the application logo, the "SFT Studio Pro" name, and a v1.0 version pill. This identifies the application and the installed version.

State

Example counter

The supplied screenshot shows a counter reading "115 ex." adjacent to the version pill. The supplied documentation does not describe how this counter is computed; treat it as a live dataset-size indicator displayed in the header.

Selection

Project selector

Displays the active project name — the supplied screenshot shows a truncated project label. Use it to confirm which project the current session operates on. The supplied documentation does not describe its dropdown behavior.

Action

+ New

Starts a new project. Any confirmation dialogs it may present are not described in the supplied documentation.

Action

Save

Saves the current project state.

Action

Support

Opens the in-app App Support panel. In narrow layouts the header may render this label as the truncated "Supp…"; see Section 11 for the support workflow.

Action

Account

Opens account-related options. In narrow layouts the header may render this label as "Acco…". The exact account behaviors are not described in the supplied documentation.

Action

Logout / exit

The supplied screenshot shows an exit-style control near the session actions. The supplied documentation does not describe its exact behavior, so none is asserted here.

1.2 Numbered Workflow Navigation

Beneath the header, the Studio exposes a numbered navigation that reflects the workflow order. Steps confirmed by the supplied documentation include Project Definition, Synthetic SFT Batch Generator, Document to SFT, Dataset Registry, and App Support. The Dataset Registry item displays a count badge noting how many batches currently exist in the registry (see Section 7). Sections 2–10 of this manual map to the workflow's major stages; Section 11 covers the in-app support area.

Note

Labels such as "Supp…" and "Acco…" are space-truncated renderings that appear when the header lacks horizontal room. The underlying destinations are Support and Account respectively.
