Section 4 · Document-to-SFT Conversion

Document-to-SFT Conversion

Purpose of this section: a button-by-button guide to turning existing source material into candidate supervised fine-tuning examples. Document conversion lets you start with existing source material instead of manually constructing every training example. The Studio treats the converted material as candidate SFT data. Conversion is therefore an extraction-and-synthesis stage, not the final quality gate. The source documentation specifically warns that conversion can introduce malformed joins, missing context, duplicated material, or examples whose target behavior is unclear; converted batches go through the same review and quality-assurance process used for generated material.

4.1 Entering the Document-to-SFT Workflow

The conversion workflow is reached from the Studio navigation using the "2. Document to SFT" control. The converter is designed for raw technical texts, manuals, literature, and transcripts that can be transformed into structured fine-tuning conversational logs. The screen also shows the project as Locked. This matters because the conversion screen works from the locked project definition rather than inviting you to redefine the project here.

4.2 Supplying the Source Document

Input

Upload DOCX, Doc, PDF, or Image (OCR)

The visible upload area for source material. The screen states that the user can click to select a file or drag and drop supported material. Supported formats shown in the interface: DOCX, Markdown, TXT, JSON, CSV, PDF, and image files in PNG/JPG/WebP. The screen also explicitly labels image input as OCR-capable.

Input

Paste Raw Document Content

The converter also exposes a raw-text path. Use this when the source content is already available as text and does not need to arrive through a file upload.

State

Locked Project

This status indicator confirms that the project is locked while the conversion workflow is being used. The source does not document a separate unlock action on this screen, so this manual does not infer one.

Action

Clear Upload

Appears after a document has been loaded. Clears the current uploaded source from the conversion screen — the explicit control for removing the uploaded document.

Result

Extraction result

After a document is supplied, the converter reports the extraction outcome — the supplied screenshot shows successfully extracted pages together with character counts. Use this report to confirm the source was actually read before proceeding.

4.3 Conversion Output Is Candidate Data

Conversion produces candidate SFT examples, not finished training data. The source documentation specifically warns that conversion can introduce malformed joins, missing context, duplicated material, or examples whose target behavior is unclear.

Warning from the source documentation

Converted batches go through the same review and quality-assurance process used for generated material. Treat conversion as an extraction-and-synthesis stage, then audit the resulting batch with the AI Quality Assessor (Section 6) before it reaches the registry selection in Section 7.
