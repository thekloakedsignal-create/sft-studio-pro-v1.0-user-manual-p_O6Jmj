Section 5 · Optional TRiAD Alignment

Optional TRiAD Ethics Alignment

Purpose of this section: a button-by-button guide to the optional Freedom, Truth, and Kindness alignment stage. TRiAD alignment is an optional stage built around a balanced FTK model: Freedom, Truth, and Kindness. The source documentation describes FTK as an equilibrium rather than a hierarchy in which one value automatically outranks the others. The purpose of this stage is to add pre-generated alignment examples to the project — it is not a replacement for defining the target behavior, and not a substitute for the normal review and quality-assurance pipeline.

5.1 What TRiAD Alignment Is

TRiAD alignment adds pre-generated Freedom/Truth/Kindness examples to the project. According to the source documentation, the FTK values are held in equilibrium: no single value automatically outranks the others.

Warning from the source documentation

The documentation specifically warns against treating TRiAD as a magical moral coating for a poorly designed dataset. Use it deliberately when the training objective genuinely includes conversational judgment, moral tradeoffs, integrity, or relational behavior.

5.2 The TRiAD Alignment Panel

The first screen identifies the feature as TRiAD Alignment and labels the source as PRE-GENERATED. The panel states that its purpose is to add pre-generated TRiAD alignment examples to the project.

5.3 PRE-GENERATED

The PRE-GENERATED label identifies the alignment material as pre-generated rather than material the user is authoring one example at a time in this panel. The documentation says the user chooses a batch size and template, after which the system can inject the project-specific system prompt or project context into those pre-generated examples before importing them.

The visible panel also explains that this option is for alignment only, not file uploads. In other words, this screen is not the document-ingestion workflow covered in Section 4.

5.4 Choose a Batch Size and Template

The panel instructs the user to choose a batch size and template for the pre-generated TRiAD alignment dataset. The source documentation does not provide a prose list of all available sizes; however, the second screenshot visibly shows the available Maximum Import Size choices of 150 Examples, 300 Examples, and 750 Examples, with the 150-example option selected.

5.5 Automated Script Behavior

State

Batch Template Type: LOCKED (ChatML)

The screenshot shows the batch template type marked LOCKED with ChatML as the locked value. The template is fixed for the import; it is not an editable choice on this panel.

Selection

Maximum Import Size

The screenshot shows three import-size choices — 150 Examples, 300 Examples, and 750 Examples — with 150 selected. These determine how many pre-generated alignment examples are imported.

Action

Run Script and Import

The visible action button executes the automated script described by the panel: it injects the project-specific system prompt or project context into the pre-generated TRiAD examples and imports them into the project. The source documentation describes this injection behavior explicitly.

State

Optional and skippable

The panel notes that this step may be skipped entirely. TRiAD alignment is optional; skipping it does not block the rest of the pipeline.

Like every other batch-producing stage, imported TRiAD material still flows through the Dataset Registry and the AI Quality Assessor before it can be included in the compiled dataset.
