SFT Studio Pro v1.0 · User Manual

User Manual

Purpose of this manual: a button-by-button guide to SFT Studio Pro covering the full supervised fine-tuning dataset pipeline — from project definition, through generation, conversion, alignment, quality assurance, and registry selection, to compile, formatting, and JSON/JSONL export.

Each section corresponds to a stage of the workflow. Where the supplied documentation does not describe a behavior, this manual says so explicitly rather than inventing behavior. Every section listed below is complete and ready to use.

01

Application Shell & Navigation

Orient yourself to the Studio header controls and the numbered workflow navigation that carries you from project definition to export.

Ready 02

Project Definition

Define the persona, system prompt, and target exemplar that every later generation and conversion stage operates against.

Ready 03

Synthetic SFT Batch Generator

Generate synthetic candidate SFT examples in batches and send them to the Dataset Registry for review.

Ready 04

Document-to-SFT Conversion

Turn uploaded documents or pasted raw text into candidate SFT examples, then apply the same QA rigor as generated batches.

Ready 05

Optional TRiAD Alignment

Optionally import pre-generated Freedom/Truth/Kindness alignment examples into the project.

Ready 06

AI Quality Assessor

Audit a registry batch, interpret the audit score and flags, and decide whether to repair, regenerate, or approve.

Ready 07

Image & Data Registry

Select QA-checked batches for inclusion in the final dataset — the handoff point before compile.

Ready 08

Compile

Combine selected registry batches into one working dataset with an automatic ~10% validation partition.

Ready 09

Format

Apply a target export template (e.g., ChatML) and inspect the formatted output preview before export.

Ready 10

Export

Download or copy JSON and JSONL for both the training set and the validation subset.

Ready 11

Support & Troubleshooting

Use the in-app Studio Expert for questions about the application and the current project, and route common issues to the right section.
