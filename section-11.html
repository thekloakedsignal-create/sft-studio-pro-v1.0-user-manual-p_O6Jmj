Section 11 · Support & Troubleshooting

Studio Expert / App Support

Purpose of this section: use the in-app Studio Expert to ask questions about SFT Studio Pro and the project you are currently working on, and route common issues to the right manual section. Studio Expert is designed to help you understand the application and make decisions inside the workflow without leaving the studio.

11.1 The App Support Panel

Studio Expert is the in-app support area for asking questions about SFT Studio Pro and the current project. This section explains what the support area is for, what kinds of questions it can handle, and how to use the controls shown in the interface.

The empty state presents the prompt "How can I help you with SFT Studio Pro?" with helper text listing supported topics: defining personas and system prompts, generating examples, document conversion, quality audits, and exporting your dataset. The panel header shows the label "App Support" with the placeholder-level text "Ask anything about u…" — the supplied screenshot truncates this string, and the full wording is not documented.

Action

Quick-help prompt chips

Pre-written prompts that seed common questions. The screenshot shows chips such as "How do I use SFT Studio". Selecting a chip starts the conversation.

Action

Header reset control

A refresh-style control appears in the panel header. Its exact behavior — for example, whether it clears the current conversation — is not described in the supplied documentation, so treat it as present but undocumented.

Input

Message composer

The free-text field at the bottom of the panel, used to ask your own question when the quick-help chips do not cover it.

11.3 Troubleshooting Routes

Route problems to the stage that owns them:

  • Quality questions and flagged examples → the AI Quality Assessor (Section 6).
  • Batch selection issues → the Image & Data Registry (Section 7).
  • Export counts or totals that look wrong → Compile (Section 8); recheck the selection as described in Section 8.3.
  • Template and representation questions → Format (Section 9).
  • Understanding a screen or choosing a control → the Studio Expert panel itself.
