Section 8 · Compile

Compile & Export SFT

Purpose of this section: combine the QA-checked batches selected in the Dataset Registry into one working dataset, automatically partition approximately 10% into a validation subset, and see the real size of the dataset being prepared for training.

8.1 Selected Dataset Breakdown

Compile & Export is where the QA-checked batches selected in the Dataset Registry become one working dataset. The Studio combines the selected batches and automatically partitions approximately 10% into a validation subset, leaving the remainder as the training set. This is the first screen where you can see the actual size of the dataset you are preparing for training.

Result

Included Batches

How many Registry batches are being compiled. The documented example shows 5.

Result

Total Selected SFTs

The combined number of examples across the included batches. The documented example shows 115.

Result

Training Set Size

The remainder after the validation partition. The documented example shows 103 examples.

Result

Validation Set Size (10%)

The Studio automatically partitions approximately 10% into a validation subset. The documented example shows 12 examples. You do not create this subset manually.

Selection

Target Export Template Format

The template the dataset will be formatted for; the documented example shows ChatML. Applying the template is covered in Section 9.

8.2 What the Compile Stage Does

Compile assembles the selected material. It does not require you to manually create the validation subset. The Studio shows the resulting counts before export so you can see what will be produced.

8.3 What to Check

Look at the number of included batches and total examples. If the selection is wrong, return to the Dataset Registry (Section 7) and change the selected batches. If the selection is right, continue to formatting and export.

The compile stage is also a useful composition check. A collection of individually good batches can still become unbalanced when combined, so this is a good place to notice an obviously dominant or repetitive batch.
