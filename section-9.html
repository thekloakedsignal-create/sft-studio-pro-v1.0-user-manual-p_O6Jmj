Section 9 · Format

Template Formatting & Output Preview

Purpose of this section: apply a target export template (such as ChatML) to the approved dataset, and inspect the formatted output preview before export. Formatting changes how an approved dataset is represented for a particular training pipeline — you do not regenerate the underlying examples just because the target format changes.

9.1 Target Export Template

Selection

Target Export Template Format

The template selector. The documented example shows ChatML_TOKEN with ChatML Instruction selected. The description beneath the selector explains the representation: in the ChatML instruction variant, role boundaries use special tokens such as <|im_start|> and <|im_end|>.

9.2 Apply the Template

Action

Format Dataset to ChatML Instruction

Applies the selected template to the dataset.

Action

Apply to Batches

Runs the formatting operation on the selected batches.

9.3 Formatted Dataset Output Preview

The preview shows how the chosen template represents the data. The panel presents variants including a JSONL single-line record, a pretty JSON structure, and a validation dataset view. Use it to inspect role boundaries, special tokens, and the overall structure before exporting.

9.4 Copy JSON Preview

Action

Copy JSON Preview

Copies the displayed preview so you can inspect it or paste it elsewhere.

Workflow

Choose a template → apply it → inspect the preview → export (Section 10).
