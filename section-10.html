Section 10 · Export

JSON and JSONL Exports

Purpose of this section: export the compiled training set and the validation subset as JSON or JSONL, or copy the JSONL content directly to the clipboard. SFT Studio Pro provides both formats for both datasets.

10.1 Training Set

Action

Export JSON

Downloads the training set as JSON.

Action

Export JSONL

Downloads the training set as JSONL.

Action

Copy Training JSONL to Clipboard

Copies the training JSONL content to the clipboard.

10.2 Validator Subset

The Validator Subset block shows the validation item count and provides the same three actions: Export JSON, Export JSONL, and Copy Validation JSONL to Clipboard.

10.3 JSON and JSONL

JSON is convenient for browsing and inspection. JSONL stores one JSON record per line and is the practical machine-learning artifact for many training pipelines.

Keep the training and validation outputs clearly separated so the relationship between the two datasets stays obvious.

10.4 Machine-Readable Output

The exported representation uses the template chosen at the Format stage. The sample below shows the ChatML structure — a short excerpt, not a full record:

[
  {
    "text": "<|im_start|>user\nSocrates, surely you would agree that the pious is simply whatever the gods love?\n<|im_end|>\n<|im_start|>assistant\n<think>\nThe user proposes Euthyphro's definition: piety as what the gods love. Expose its flaws with leading questions; stay in persona.\n</think>\n\nA swift and confident answer, my friend — almost too swift. But indulge an old man with a few small questions before we crown your definition…\n<|im_end|>"
  }
]

Inspect the exported representation at least once. Check the record count, schema, template tokens, role ordering, and expected validation split.

10.5 Export Confirmation

The application can display a confirmation showing that the dataset was exported in the selected template format — the documented screenshot shows the message "Exported sft_training_dataset.json successfully in [CHATML_TOKEN] template format!" alongside the Dataset Registry header.
